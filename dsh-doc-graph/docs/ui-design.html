IndexStatusCard

对话中实时显示进度 + 统计（N 文档 / M 节点 / K 边）

→
4

问答与分析

过期审计 / 引用影响 / 相似文档 / 上下文检索，全部以卡片渲染

核心闭环：一次索引 → 多次查询 → 卡片持久在会话里可回看。会话重放时卡片从持久化 meta 恢复，不依赖临时文件。

插件形态

Node 端（模型侧）src/index.ts

Cordis 插件注册 9 个 docgraph_* 工具 + 1 个 bundled skill。工具直接进程内桥接 Go core binary，不额外起 MCP server 进程。

Client 端（UI 侧）src/client/index.tsx

toolview 注册 GraphCard / ContextCard / DriftAuditCard / IndexStatusCard；dock 注册 DocGraphDock 状态条。无 client 时降级为文本结果（TUI 兼容）。

.rst（标题/引用语法）· .tex（章节 + \ref + \cite）

P2

.odt（zip + content.xml）· .epub（zip + xhtml 章节）· 扫描 PDF OCR（tesseract）
